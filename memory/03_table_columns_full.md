# Table Columns Full

## Source Of Truth

Full column definitions are migration-owned. This file records the table-level
column sources and the business interpretation rules. When columns change, update
the migration/model first and regenerate this document from the source.

## Column Ownership Rules

- `id`: database primary key, database managed.
- `public_id`: public route key, generated by `HasPublicId` where model uses it.
- `created_at`, `updated_at`: Eloquent managed.
- `deleted_at`: Eloquent `SoftDeletes` managed.
- `created_by`, `updated_by`, `deleted_by`: controller/model workflow managed.
- Log table `old_values` and `new_values`: `HasActivityLogging` managed.
- Log table device fields: `HasActivityLogging` plus request/user-agent context.
